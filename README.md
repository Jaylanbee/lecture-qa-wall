## 🎯 現場三步作戰閉環

1. **開場投影**：電腦開啟 [首頁網址](https://jaylanbee.github.io/lecture-qa-wall/)，左側即為超大、高清晰 QR Code，按 F11 即可全螢幕放映。
2. **學生掃碼提問**：學生手機掃描 QR Code，填寫問題與 Email，取得專屬序號（`#1`, `#2`...），大螢幕每 4 秒自動同步浮現最新問題。
3. **課後講義回贈**：點擊右上角「📥 匯出名單 (CSV)」，一鍵下載完整信箱與提問名單，輕鬆批次寄送演講講義！
